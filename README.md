# Denmark | Common design library: Common UI components based on Material UI and React JS
# React UI components - webpack based project

# This project was generated with latest webpack 5 and React dependencies.

Node Versions: 16 and above. This is developed on React JS 18.2.0 and Material UI 5.11.16

## Development server http://localhost:3000/

npm run start

## build, will create dist folder with umd file

npm run build

## To make available as a npm modules inside @denui/denmark-ui-components. Run below commands in LOCAL machine 

npm localpublish

## To make available as a npm modules inside @denui/denmark-ui-components. Run below commands in PROD 

npm prodpublish

## To use it inside any other project and will be available in your project node modules, run below command.

npm install @denui/denmark-ui-components

## To run it as a storybook, run below commands and open http://localhost:6006/ in browser

npm run storybook
